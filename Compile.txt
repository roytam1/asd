Complete sources released under GPL2

tested with

with Borland c++ for windows/dos version
with gnu gcc for Linux version
with Microsoft Visual C++ 6.0 for the windows version

Linux
edit asd.h and change define to __UNIX__


Windows/Dos
edit asd.h and change define to __WINDOWS__

Windows with Microsoft Visual C++ 6.0
run build.bat
it calls VCVARS32.BAT and builds asd.exe and unasd.exe
(the exe's are placed in the build subdirectory)

asd.exe   = create/list/extract/test archives and create sfx files
unasd.exe = list/extract/test archives
